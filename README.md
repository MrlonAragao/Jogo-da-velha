🕹️ Jogo da Velha (Tic-Tac-Toe)
Uma implementação moderna e responsiva do clássico Jogo da Velha, desenvolvida com foco em interface limpa e experiência do usuário.

🚀 Sobre o Projeto
Este projeto faz parte do meu portfólio de desenvolvimento, onde apliquei conceitos de lógica de programação, manipulação de DOM e estilização avançada com CSS. O jogo permite que dois jogadores joguem localmente, alternando entre as jogadas até que haja um vencedor ou um empate ("velha").

🛠️ Tecnologias Utilizadas
HTML5: Estrutura semântica do jogo.

CSS3: Estilização moderna, uso de Flexbox/Grid e efeitos de hover.

JavaScript: Lógica central, verificação de condições de vitória e reinicialização do estado do jogo.

🎮 Como Jogar
Abra o arquivo index.html em seu navegador.

O primeiro jogador clica em qualquer quadrado para marcar sua jogada.

O jogo alterna automaticamente entre os jogadores.

O sistema detecta automaticamente vitórias em linhas, colunas ou diagonais.

Clique no botão "Reiniciar o jogo" para começar uma nova partida a qualquer momento.

🖼️ Interface
O layout foi desenhado para ser intuitivo e focado no tabuleiro:

Tabuleiro: Grade 3x3 com feedback visual.

Botão de Reset: Acesso rápido para reiniciar a lógica do jogo.

Design: Paleta de cores vibrante (tons de rosa e azul escuro) para uma estética moderna.
